Experimental ARM64 foundation, built from the Bazzite fork.
Includes native Fedora KDE, Mesa/Venus, gamescope, Lutris and FEX.
This is not a full Bazzite port and does not contain Steam, Proton, an x86
FEX rootfs, Bazzite Game Mode, or the steamac guest integration.
It cannot replace steamac's steamos.img or be booted with its stock initramfs.
See the repository docs/arm64.md before using this image.
